## 验收策略说明

全工作簿验收当时使用确定性 gold collector，目的是验证平台自身的规划、状态、审核和 Excel 重建是否无损。V2.4 将该模式明确降级为“平台管线回归”，不得再对外宣称为采集效果验收。

新的项目验收边界是：平台仅获得空表、正常业务配置和独立冻结的原始来源 Fixture；运行完成后，另一个与生产包隔离的验收进程才可读取历史金标并比较。Fixture 不得从金标反向生成。
