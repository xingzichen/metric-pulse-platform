# ADR-0007：ai_index 原始值、单位转换与联合约束

- 状态：已实施
- 日期：2026-08-24
- 取代范围：所有把 `be_data` 与 `data` 视为等价值、把工作簿已有 `be_unit` 视为采集结果的实现和说明

## 背景

`人工智能指标库（ai_index）` 的一行不是“找一个数字”，而是一个受业务语义约束的指标观测。
指标主体是 `index_name`，并由 `level、region、province、city、district、other_region、
statistical_date、scope、industry` 的所有非空值共同限定。

字段语义固定为：

- `be_data`：来源中直接观察到的原始数值；
- `be_unit`：与原始数值来自同一来源定位的原始单位；
- `unit`：工作表定义的标准目标单位，不是模型自由生成的事实；
- `data`：把 `be_data` 从 `be_unit` 换算到 `unit` 后的标准数值；
- `source_url`：实际支持原始值和原始单位的网页或附件 URL。

当前通用字段识别只把空值率较高的列选为目标，导致已有单位提示的 `be_unit` 没有进入采集组；
采集提示词和结构化提取又把同一个数字同时写入 `be_data/data`。这会在
`百万美元 → 亿美元`、`ZFlops → EFlops` 等行产生确定性错误。

## 决策

### 1. ai_index 使用专用字段角色

每个 ai_index 单元原子处理 `be_data + be_unit + data`。即使输入工作簿的 `be_unit` 已有值，
它也只是搜索和识别提示，不是已核验的来源单位；最终 `be_unit` 必须由当次来源证据产生。
当输入 `source_url` 为空时，`source_url` 同时进入本单元的必需输出组。

`index_name` 是唯一主体。一级/二级分类和 `industry_id` 仅作为辅助上下文，不能替代主体或
放宽联合约束。所有非空业务约束必须在复核结果中逐项给出匹配结论，缺失或冲突时失败关闭。

### 2. 程序转换优先

模型只负责从证据提取原始值/单位和理解复杂单位表达。应用首先使用版本化确定性单位注册表：

1. 单位规范化与别名折叠；
2. 相同维度的 Decimal 倍率换算；
3. 记录输入值、原始/目标单位、倍率、公式、结果和规则版本；
4. 用程序重新计算并校验最终 `data`。

注册表首先覆盖现有表中的单位族：人民币/美元数量级、人数/个数等中文计数前缀、FLOPS SI
前缀、字节 SI 前缀，以及 `%、分、次、家、枚` 等同单位传递。现有表已经明确出现的
`百万美元 → 亿美元` 与 `ZFlops → EFlops` 必须有程序测试。

来源单位与标准单位在表结构中同时为空时表示无量纲指标。程序执行倍率为 1 的恒等转换，
`be_unit` 和 `unit` 继续保持空白，并把该空值记录为合法的“无单位”状态而不是漏采。

### 3. 模型转换只作降级

只有以下条件全部成立才允许使用双阶段模型已经返回的转换候选，不新增第三次模型调用：

- `be_data/be_unit` 已由被引用来源批准；
- `unit` 非空；
- 确定性转换返回 `UNSUPPORTED`，而不是缺值、非数值或已知维度冲突；
- VERIFY 明确返回转换输入、目标单位、公式、结果和置信理由；
- 应用检查模型没有改变原始值/单位，且输出是有限数值。

模型降级结果标记为 `MODEL_FALLBACK` 和高风险，必须人工审核；不得进入自动批准。涉及汇率、
通胀、估算口径或跨维度计算时，没有同一来源中的转换依据一律不允许模型猜测。

### 4. 缺失和失败语义

- 原始值缺失，或仅有一侧单位缺失：`UNRESOLVED`；两个单位同时为空的无量纲指标除外；
- 原始值/单位已核验，但 `unit` 缺失或转换不可完成：`PARTIAL`；
- 单位维度明确冲突或转换结果非法：`INVALID`；
- 确定性转换成功：可按其他证据门禁继续判定；
- 模型降级成功：结果可保存，但保持高风险和人工审核必需。

当 `be_unit` 有值但 `unit` 为空时，只允许从已确认、唯一的指标单位配置自动补齐；不得根据
模型偏好或同一行的原始单位静默决定标准单位。审核工具应同时展示原始值、原始单位、目标
单位、公式和失败原因。

### 5. 来源 URL

仍遵守 ADR-0006 的直链优先。无输入链接时，搜索 URL 先作为候选 Evidence；只有 VERIFY 批准
原始值/单位并引用该文档，或人工修正后选择具体事实来源，才把实际网页/附件 URL 写入
`source_url`。搜索结果页、摘要或未被选中的候选不能回填。

## 后果

现有旧语义任务结果不可平滑复用。完成代码和回归后清空旧任务运行数据，从空表重新规划。
生产仍不知道外部金标；历史表只用于沉淀字段/单位规则，不能用于提供预期业务值。

## 验收

1. ai_index 每个单元都采集 `be_data/be_unit` 并程序生成 `data`。
2. 全部非空联合约束进入 RowContract，VERIFY 逐项返回匹配矩阵。
3. `500 百万美元 → 5 亿美元`、`2 ZFlops → 2000 EFlops` 程序换算通过。
4. 已知维度冲突、缺少目标单位和非数值输入不调用模型转换降级。
5. 仅 `UNSUPPORTED` 可使用双阶段模型的转换候选，并强制高风险人工审核。
6. 无输入链接的已解决结果必须有一个被选中的实际来源 URL。
7. 每行仍只有 `SYNTHESIZE → VERIFY` 两次 Qwen 请求，全局并发仍为 1。
