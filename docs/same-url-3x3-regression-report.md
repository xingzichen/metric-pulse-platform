# 相同 URL 3+3 回归报告

日期：2026-08-25

模型：`Qwen3.8-27B-6bit`，OMLX `max_model_len=131072`，全局并发 1

## 用例与边界

- 百家号来源：`https://baijiahao.baidu.com/s?id=1742955719106424432`，空表 `ai_index`
  第 8103、8108、8113 行，分别为爱尔兰、爱沙尼亚、澳大利亚。
- World Bank 来源：`https://data.worldbank.org.cn/indicator/GB.XPD.RSDV.GD.ZS?locations=US`，
  空表 `ai_index` 第 6892、6893、6894 行，分别为 2018、2019、2020。
- 百家号在线页面会触发挑战风险，本次真实文本模型回归使用此前从该 URL 成功抓取并由视觉模型
  转写的 46 行冻结快照；不会为了测试重复撞站点。World Bank 通过生产适配器实时规范化到中文
  官方 API。
- 可重复离线用例 `tests/test_same_url_3x3_regression.py` 使用冻结原始证据替身，验证完整平台控制流：
  两个 URL 总计获取 2 次、百家号图片识别 1 次、六行各自两次文本模型调用。

## 真实 OMLX 结果

| 空表行 | 地区/年份 | 期望值 | 实际值 | 来源缓存 | 同阶段 OMLX 缓存 |
|---:|---|---:|---:|---|---:|
| 8103 | 爱尔兰 / 2021 | 16.68 | 16.68 | 持久缓存 | 0 |
| 8108 | 爱沙尼亚 / 2021 | 15.14 | 15.14 | 持久缓存 | 2,048 token |
| 8113 | 澳大利亚 / 2021 | 26.81 | 26.81 | 持久缓存 | 2,048 token |
| 6892 | 美国 / 2018 | 2.98956 | 2.98956 | 首次网络获取 | 0 |
| 6893 | 美国 / 2019 | 3.14297 | 3.14297 | 进程缓存 | 0 |
| 6894 | 美国 / 2020 | 3.41788 | 3.41788 | 进程缓存 | 0 |

结果：6/6 正确；World Bank 官方 API 网络请求 1 次；12 次文本调用均为
`finish_reason=stop`。行级调用的 prompt 为 1,059–2,731 token，completion 为 130–274 token，
没有接近 4,096 输出上限。

百家号长图文前缀在第二、三行的 `SYNTHESIZE` 和 `VERIFY` 均命中 2,048 cached token；首行
单次约 56–58 秒，后续约 24–32 秒。World Bank 证据较短（prompt 约 1,060 token），本次未出现
KV 命中；这是服务端缓存粒度/最短前缀造成的合理现象。相邻调度仍使其只发一次网络请求，因此
来源亲和排序对短、长来源都有效，但 OMLX KV 收益主要出现在较长且稳定的共享正文。

## Token 配置结论

| 配置 | 上线值 | 结论 |
|---|---:|---|
| 全局兜底 | 4,096 | 覆盖未分阶段调用 |
| 工作表分析 | 2,048 | 结构 JSON 足够 |
| `SYNTHESIZE` | 4,096 | 本次最大仅 140 |
| `VERIFY` | 4,096 | 本次最大仅 274 |
| `VISION_TABLE` | 8,192 | 给 46 行及更长图片表留量 |
| 视觉截断重试 | 16,384 | 只在 `length`/截断 JSON 时使用一次 |

128K 是输入文本、图片 token 与最大输出预算的总和。当前逐行证据仍限制为 30,000 字符，实测
本组输入远低于上下文上限；把所有阶段统一提高到 16K 没有质量收益，反而扩大最坏延迟和资源预留。

  --workbook ../人工智能-空表--250224-V1.xlsx \
